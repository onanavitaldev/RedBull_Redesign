# Red Bull - Interactive Alternative Landing Page

A modern, high-impact, and minimalist landing page concept for Red Bull, built with Vue.js 3, Tailwind CSS, and GSAP ScrollTrigger. Designed with an underground, subversive aesthetic, featuring ultra-smooth animations, fluid sound design, and responsive streaming-style layouts.

## Key Features

- **Dynamic iOS Glassmorphic Navbar**: Floating pill-style header with a blur effect that adjusts dynamically on scroll.
- **Hero Carousel**: High-definition video and imagery showcase with interactive story cards and auto-play logic.
- **Pinned GSAP Energy Drinks Section**: Interactive 3D product showcase pinned on scroll with seamless flavor transitions, dynamic background gradients, and custom drop animations.
- **Minimalist Stories Grid**: High-contrast news cards with GSAP reveal animations upon scrolling.
- **Slim Events Carousel**: Light-mode, tactile horizontal slider featuring international concerts, esports championships, and street culture events.
- **Immersive Athletes Streaming Section**: Fullscreen dark-mode profile slider inspired by modern video streaming platforms.
- **Red Bull TV Interface**: Amazon Prime Video-style spotlight banner accompanied by horizontal media tracks.
- **Brand Gradient Footer**: Glassmorphic subscription interface built over Red Bull's signature dark blue, red, and yellow color gradient.

## Tech Stack

- **Language**: JS
- **Styling**: Tailwind CSS
- **Animations**: GSAP  & ScrollTrigger
- **Typography**: Montserrat & Anton Google Fonts
